## 🎨 Portfolio Website

This repository contains a modern, aesthetic portfolio website built with React JS for Software Engineer, Designer, and IT Technical professionals.

### Quick Start

```bash
cd portfolio-app
npm install
npm run dev
```

For detailed instructions, see [QUICKSTART.md](QUICKSTART.md)

### Features

- ✨ Modern & Aesthetic Design
- 📱 Fully Responsive
- 🎯 Multiple Sections (Hero, About, Skills, Projects, Contact)
- 🎨 Glass Morphism Effects
- 🚀 Fast Performance with Vite
