# Modern Portfolio Website

A beautiful, responsive portfolio website built with React JS, showcasing work as a Software Engineer, Designer, and IT Technical professional.

## 🎨 Features

- **Modern & Aesthetic Design** - Clean, elegant interface with gradient accents
- **Fully Responsive** - Works seamlessly on all devices
- **Smooth Animations** - Engaging transitions and hover effects
- **Glass Morphism Effects** - Modern UI design patterns
- **Interactive Components** - Dynamic navbar, floating cards, and more
- **Contact Form** - Easy way for clients to reach out

## 🛠️ Tech Stack

- **React 19.2.0** - Modern React with hooks
- **Vite** - Lightning-fast build tool
- **React Icons** - Beautiful icon library
- **CSS3** - Custom styling with CSS variables and animations

## 📦 Installation

1. Clone the repository:
```bash
cd portfolio-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

## 🚀 Build for Production

```bash
npm run build
```

The optimized files will be in the `dist` folder.

## 📝 Customization

To customize the portfolio for your needs:

1. **Update Personal Information**: 
   - Edit `src/components/Hero.jsx` to change your name and title
   - Update contact details in `src/components/Contact.jsx`

2. **Add Your Projects**:
   - Modify the `projects` array in `src/components/Projects.jsx`

3. **Update Skills**:
   - Edit the `skillCategories` in `src/components/Skills.jsx`

4. **Change Colors**:
   - Modify CSS variables in `src/App.css` (`:root` section)

5. **Social Links**:
   - Update links in `src/components/Hero.jsx` and `src/components/Footer.jsx`

## 📱 Responsive Design

The portfolio is fully responsive and optimized for:
- 📱 Mobile devices (320px and up)
- 📱 Tablets (768px and up)
- 💻 Desktop (1024px and up)
- 🖥️ Large screens (1200px and up)
